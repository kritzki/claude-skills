# Claude skills

Free, plain-text skills for Claude. No scripts, no tracking, no access to your accounts.

| Skill | What it does | Download |
|---|---|---|
| [scam-check](scam-check/) | Checks crypto messages, links, wallet addresses and signature requests for scam signs. Answers SAFE, CHECK or SCAM with the reason. | [scam-check.zip](scam-check.zip) |

## How to install a skill
- **Claude app:** Settings, Capabilities, Skills, upload the ZIP.
- **Claude Code:** unzip into `~/.claude/skills/`.

Skills here are helpers, not guarantees. Always read a skill before you install it, including these.
